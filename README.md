# Program Kasir Mini (Python)

Repository GitHub:
https://github.com/yuliantiveronikasidabutarrr-source/kasir-minii-python

Program kasir mini berbasis Python untuk memenuhi tugas mata kuliah
Algoritma dan Pemrograman.

## Fitur Program
- Input kategori dan barang
- Perhitungan total belanja
- Diskon 10% jika total ≥ Rp500.000
- Menampilkan struk pembelian

## Konsep yang Digunakan
- Input – Process – Output (IPO)
- Perulangan (for)
- Percabangan (if)
- Struktur data: dictionary, list, tuple

## Cara Menjalankan
```bash
python kasir_mini.py
```
